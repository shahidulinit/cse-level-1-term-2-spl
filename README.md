# CSE Level 1 Term 2 - SPL

This repository contains C programming work for CSE Level 1 Term 2.

## Folders

- [`assignment/`](./assignment/) contains the Assignment 1 pattern-printing
  programs and an easy-to-follow explanation of each program.
- [`ct1/`](./ct1/) contains the CT1 question solutions, their topic index, and
  the VS Code build task.

Open the folder for the work you want to run in VS Code. Each folder has its
own README with compile and run instructions.
